\title{Guardian-APC+: Rewrite-Aware, Coverage-Guided Boundary Probing\\for Per-Pass Validation of ML Compiler Rewrites}

\author{\IEEEauthorblockN{Vaishnavi}
\IEEEauthorblockA{Department and institution (fill in)\\

\begin{abstract}
Machine-learning compilers rewrite computation graphs to make inference cheaper, and one faulty rewrite can silently change predictions. Formal translation validation is precise but heavyweight. Random differential testing is cheap but rarely reaches the inputs where piecewise-linear networks are fragile. We present \emph{Guardian-APC+}, a lightweight per-pass validator built into the ModelForge model compiler. It (i)~uses interval bound propagation (IBP) to find ReLU units whose kink is reachable, (ii)~places test inputs exactly on each unstable kink \emph{at every depth} with Newton steps on the exact input gradient, (iii)~orders inputs by \emph{activation-pattern coverage} (APC), a submodular objective with a $(1-1/e)$ greedy guarantee, (iv)~focuses on the activations a rewrite actually touches, and (v)~turns sub-tolerance output differences into a search signal (\emph{near-miss search}). A rejected rewrite is rolled back with a minimised witness and the first IR value where the two graphs diverge. In an equal-budget study over 96 synthetic models and 2{,}160 injected faults, Guardian-APC+ detects 99.2\% of observable faults with 128 inputs, against 75.0\% for uniform random testing and 85.6\% for the previous Guardian (exact McNemar $p<10^{-4}$). With only 8 inputs it detects 88.2\%, against 79.9\% without rewrite awareness ($p=1.4\times10^{-22}$) and 57.9\% for random testing. It raises no false alarm on 96 negative controls, and the low-budget gain replicates under three further seeds.
\end{abstract}

\section{Introduction}
Graph-level optimisation is central to ML compilers such as TVM~\cite{tvm} and Glow~\cite{glow}: operators are fused, constants folded and dead nodes removed. These rewrites are easy to get subtly wrong, and model generators such as NNSmith~\cite{nnsmith} have found many such bugs in production compilers. Formal approaches verify rewrite rules once and for all~\cite{tensorright} or validate each compilation with solvers~\cite{necula,pnueli,alive2}, but they need a formal semantics for every operator. Differential testing with random inputs is cheap and semantics-agnostic, yet it seldom lands where ReLU networks are most fragile: next to a kink.

We ask a narrow, testable question: \emph{for a fixed number of test inputs, can inputs derived from the model's own activation boundaries, and from what the rewrite changed, expose faulty graph rewrites more often and earlier than random or generic inputs?} We answer it with Guardian-APC+, implemented in the open-source ModelForge compiler (C++17), and an equal-budget, paired, multi-model study.

\textbf{Contributions.}
\begin{enumerate}
\item \textbf{Deep boundary probing.} IBP selects unstable ReLU units; Newton iterations on the exact forward-mode gradient place inputs on each unit's kink at any depth, then at fixed offsets on both sides (\S\ref{sec:boundary}).
\item \textbf{Activation-pattern coverage (APC)} with an IBP-refined denominator, and a greedy schedule with a $(1-1/e)$ prefix guarantee (\S\ref{sec:apc}).
\item \textbf{Rewrite-aware targeting}: a structural diff of the IR before and after a pass selects the impacted activations, which get boundary inputs and coverage priority first (\S\ref{sec:delta}).
\item \textbf{Near-miss search}: output and internal differences below the tolerance guide a hill-climb toward an observable failure (\S\ref{sec:nearmiss}).
\item \textbf{Divergence localisation and a model diff mode} that tell a developer where two graphs first disagree (\S\ref{sec:guardian}).
\item \textbf{An open benchmark}: a seeded model zoo, 11 fault families (5 held out from the probe design), a random oracle for observability, Wilson intervals and exact McNemar tests, a terminal studio and a web dashboard (\S\ref{sec:eval}).
\end{enumerate}

\section{Background and Related Work}
\textbf{Translation validation} checks each compiler run rather than the compiler~\cite{pnueli,necula}; Alive2 does so for LLVM IR with SMT~\cite{alive2}. TensorRight proves tensor rewrite rules correct for all shapes~\cite{tensorright}. Guardian-APC+ is deliberately weaker: a pass means no input found a mismatch. In exchange it needs only an executable reference semantics and runs in milliseconds.

\textbf{Compiler fuzzing.} Csmith~\cite{csmith} and NNSmith~\cite{nnsmith} \emph{generate programs or models}. We fix the model and \emph{generate inputs} that make a given rewrite's mistakes observable; the two are complementary.

\textbf{Neural coverage and verification.} Neuron coverage~\cite{deepxplore,deepgauge} is a weak adequacy proxy for model robustness~\cite{harel}. We use coverage for a different purpose, scheduling inputs to expose \emph{compiler} faults, and refine its denominator with IBP~\cite{ibp}. Complete verifiers such as Reluplex~\cite{reluplex} could tighten stability at much higher cost.

\section{Approach}
\subsection{Setting}
A model is lowered to an SSA-style IR $G$ over Gemm, MatMul, Add, ReLU, Sigmoid and Softmax. A pass proposes $G'$. Given $D=[-r,r]^n$ ($r=10$) and tolerance $\tau=10^{-5}$, an input $x\in D$ \emph{exposes} the rewrite if $\|G(x)-G'(x)\|_\infty>\tau$ or $\arg\max G(x)\neq\arg\max G'(x)$. Guardian accepts $G'$ iff none of its at most $B$ evaluations exposes it.

\subsection{Interval bound propagation}
We propagate boxes through the IR: interval products for Gemm/MatMul, sums for Add, monotone maps for ReLU and Sigmoid, and $s_i\in[(1+\sum_{j\ne i}e^{u_j-l_i})^{-1},(1+\sum_{j\ne i}e^{l_j-u_i})^{-1}]$ for Softmax. A ReLU unit with bound $[l,u]$ is \emph{stable inactive} ($u\le0$), \emph{stable active} ($l>0$) or \emph{unstable}. A liveness pass excludes activations that cannot reach the output.

\subsection{Deep boundary probes}\label{sec:boundary}
For an unstable unit $z_k(x)$ at any depth we iterate
\begin{equation}
x_{t+1}=\Pi_D\!\left(x_t-\frac{z_k(x_t)}{\|\nabla z_k(x_t)\|^2}\nabla z_k(x_t)\right),
\end{equation}
where $\nabla z_k$ is computed exactly by forward-mode Jacobian propagation under the activation pattern of $x_t$ and $\Pi_D$ clips to $D$. We start from $0$ and, if the unit is locally dead, from up to three seeded random points.
\begin{proposition}
If $G$ is piecewise linear and $x_t$ and the Newton target lie in the same linear region inside $D$, then $z_k(x_{t+1})=0$.
\end{proposition}
\noindent\emph{Proof.} In that region $z_k(x)=w^\top x+b$ with $w=\nabla z_k(x_t)$; substituting the update gives $w^\top x_t+b-z_k(x_t)=0$. \hfill$\square$

From the solved point we step to pre-activation targets $\{-0.05,\,5\!\cdot\!10^{-4},\,5\!\cdot\!10^{-3},\,5\!\cdot\!10^{-2}\}$ with one correction step each. Units are chosen round-robin across layers (at most 64).

\subsection{Activation-pattern coverage}\label{sec:apc}
\begin{definition}
Each unit's pre-activation falls into one of six bins: $(-\infty,-0.1)$, $[-0.1,0]$, $(0,10^{-3}]$, $(10^{-3},10^{-2}]$, $(10^{-2},10^{-1}]$, $(0.1,\infty)$. A (unit, bin) state is \emph{feasible} if the IBP interval meets the bin. APC is the fraction of feasible states hit by some input of the suite.
\end{definition}
Coverage is a union of state sets, hence monotone and submodular, so every greedy prefix of length $B$ covers at least $(1-1/e)$ of what the best $B$ inputs of the pool cover. Guardian orders its pool (generic inputs, first-layer affine inputs, decision-boundary bisection and deep boundary inputs) greedily by marginal gain.

\subsection{Rewrite-aware targeting}\label{sec:delta}
A pass changes a small part of the graph. Guardian-APC+ compares $G$ and $G'$ instruction by instruction (operator, operands, attributes and constant data, matched by output name) and marks every changed instruction and everything reachable from it. The \emph{impacted} ReLU sites receive their own boundary inputs, and the greedy schedule first maximises coverage of the impacted sites only; the global pool follows. If nothing upstream of the output is impacted, the global Guardian-APC schedule is used. The diff uses only the structure of the candidate, never its outputs, so the test inputs remain independent of whether the rewrite is faulty.

\subsection{Near-miss search}\label{sec:nearmiss}
Most evaluations of a faulty candidate return differences below $\tau$. We score an input by $s(x)=\|G(x)-G'(x)\|_\infty+10^{-3}\max_v\|v_G(x)-v_{G'}(x)\|_\infty$, where $v$ ranges over live intermediate values present in both graphs. After the static suite, the remaining budget hill-climbs $s$ from the four highest-scoring inputs: Gaussian moves with an adaptive step (grown by $1.5\times$ on improvement, shrunk by $0.7\times$ otherwise) alternate with whole-input amplification, which grows faults that scale with $|x|$. In the benchmark the static suite gets $3B/4$ evaluations and the search $B/4$.

\subsection{Guarded optimisation, localisation and model diff}\label{sec:guardian}
Each pass (constant folding, Gemm+ReLU fusion, dead-node removal) runs on a copy and is kept only if Guardian-APC+ finds no exposing input. On rejection, the witness is shrunk coordinate-wise toward zero while it still exposes the fault, and both graphs are traced on it to report the first value, in execution order, that differs beyond $\tau$. The same machinery compares two independently written models (\texttt{modelforge a.mforge --compare b.mforge}), for example an original and a hand-optimised or converted copy.

\section{Evaluation}\label{sec:eval}
\subsection{Setup}
\textbf{Corpus.} 96 He-initialised classifiers; depth cycles through 1 to 4 hidden ReLU layers (24 models each), widths 4 to 16, inputs 4 to 16, classes 2 to 5; each has an output-unreachable ReLU. IBP labels 2{,}346 of 2{,}357 units unstable on $D$.

\textbf{Faults.} Per activation layer: dead zones of width $10^{-1},10^{-2},10^{-3}$ (\emph{design aligned}, matching the offsets) and four further families: a dead zone of log-uniform width in $[10^{-4},10^{-1}]$, an upper clamp at a random level in $[1,6]$, a leaky ReLU with slope $10^{-2}$ (these three are \emph{held out}) and ReLU$\to$Sigmoid. Per model: a $10^{-3}$ weight and a $10^{-2}$ bias perturbation (held out), a dropped bias, Softmax$\to$Sigmoid, and a rewrite of the unreachable node as negative control. 2{,}160 faults in total; each fault plays the role of a faulty rewrite.

\textbf{Observability.} A fault is observable if any strategy or a 4{,}000-input random oracle exposes it: 2{,}021 are observable, 43 unknown (excluded), 96 controls.

\textbf{Strategies}, all at exactly $B=128$ evaluations (static suites padded with uniform random inputs): uniform random on $D$ (5 seeds), generic operator-aware inputs, Guardian v1 (generic, first-layer affine and decision-boundary inputs), Guardian-APC with three ablations, and Guardian-APC+ with two ablations (rewrite-aware static only; APC plus near-miss without rewrite awareness). Statistics: Wilson 95\% intervals and exact two-sided McNemar tests on paired outcomes.

The main benefit of the extension is speed (Fig.~\ref{fig:curve}, Table~\ref{tab:budget}). Within 8 evaluations Guardian-APC+ exposes 88.2\% of faults, Guardian-APC 79.9\%, v1 62.0\% and random 57.9\%; within 16, 95.5\%, 91.5\%, 71.9\% and 62.3\%. Counting misses as $B{+}1$, the mean evaluations to detection fall from 6.8 (Guardian-APC) to 5.7, against 40.5 for random testing. The difference vanishes at $B\ge32$.

\subsection{RQ3: Ablation}
Deep boundary inputs carry most of the detection power (98.0\% alone), but need the right order: appended after v1's inputs, the unordered union reaches 94.3\% because many deep inputs fall past the budget. APC ordering without deep inputs lowers latency (5.1) but not the ceiling (85.7\%). Rewrite awareness is responsible for the early-budget gain (88.2\% at $B=8$ both with and without near-miss search). Near-miss search mainly helps numeric faults: on the $10^{-3}$ weight perturbation it raises detection from 86 to 89 of 91 faults (94.5\% to 97.8\%), above random testing (97.1\%), where Guardian-APC was below it. In a separate run at $B=32$, near-miss without rewrite awareness \emph{lowers} detection (96.0\% vs.\ 97.1\% for Guardian-APC) because it takes evaluations away from boundary inputs; combined with rewrite awareness it reaches 97.6\%.

\subsection{RQ4: Generalisation and robustness}
For dead zones of width $10^{-3}$ Guardian-APC+ detects 240/240, v1 27.5\%, generic 17.9\% and random 4.5\%. On held-out families it detects 98.2\% (random 85.2\%, v1 90.7\%); on the held-out random-width dead zone 93.6\% (random 38.7\%, v1 64.0\%). Beyond the first layer it detects 98.8\% (v1 82.0\%). With master seeds 1, 2 and 3 (new models, faults and baselines) it detects 99.5\%, 99.4\% and 99.3\% overall, and the $B=8$ advantage over Guardian-APC replicates (243 vs.\ 71, 231 vs.\ 56 and 202 vs.\ 66 discordant pairs, all $p<10^{-16}$).

\subsection{RQ5: Cost and usefulness}
Static Guardian-APC synthesis takes 3.5\,ms per model; Guardian-APC+ spends 4.4\,ms per checked rewrite, including the diff, targeted inputs, all 128 evaluations and the search (one core, GCC 13.3, Linux). The complete study with every baseline runs in 36\,s. In the compiler, a wrong ReLU$\to$Sigmoid rewrite on the Iris demo model is rejected at the first targeted input and localised to the rewritten activation. In model-diff mode, a single mistyped weight ($0.5\to0.505$) in a hand-optimised copy of the model is exposed at the second input and localised to the layer that uses it, while a correct copy (dead node removed) passes 149 evaluations.

\section{Threats to Validity}
\textbf{Synthetic models.} Small dense networks (widths $\le16$); convolutions, attention and real ONNX models are future work. \textbf{Fault realism.} Each injected fault is the whole rewrite, so the structural diff localises it exactly; real passes change more instructions at once, which weakens rewrite awareness. Dead-zone widths partly match the offsets; held-out families are reported separately. \textbf{Loose bounds.} IBP marks almost all units unstable and proves no fault unobservable. \textbf{Oracle.} Faults no method exposes are labelled unknown, not missed. \textbf{Common-mode errors.} The interpreter and code generator share operator definitions. \textbf{Not a proof.} Passing Guardian is evidence, not equivalence.

\section{Conclusion}
Aiming inputs at the kinks of every ReLU, ordering them by activation-pattern coverage, focusing on the activations a rewrite touches and following near-miss differences gives a cheap and strong guard for ML compiler rewrites: 99.2\% detection at 128 evaluations, 88.2\% at 8, no false alarms, and a localised, replayable counterexample whenever a rewrite is rolled back. The implementation, benchmark, terminal studio and dashboard regenerate every number here with one command.
