# Review 1 Submission Checklist

Before uploading, complete the three blank fields on the first page of `Review_1_Project_Proposal_and_Design.docx`:

- Student name
- Registration number
- Submission date

Recommended Review 1 package:

1. Upload `Review_1_Project_Proposal_and_Design.docx` as the proposal and design document.
2. Keep the `prototype/` folder ready for the demonstration or source-code submission.
3. Be prepared to run the prototype using `sample_model.mforge` after building it with CMake.
4. Explain that the manifest is a Phase 1 bridge and that ONNX protobuf loading is planned for Phase 2.
5. Explain the custom IR, supported-operator scope, semantic checks, optimization plan, and ONNX Runtime comparison strategy.

Do not claim final code generation or numerical equivalence until those Phase 2 and Phase 3 components have actually been implemented and tested.
