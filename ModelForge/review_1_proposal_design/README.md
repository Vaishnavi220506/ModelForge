# Review 1 Proposal and Design

This folder contains the material for the Project Proposal and Design Review.

## Contents

- `Review_1_Project_Proposal_and_Design.docx` - uploadable proposal document.
- `prototype/` - small working C++17 prototype for the initial demonstration.

## Review 1 demonstration sequence

1. Introduce the problem and explain why a small educational ML compiler is useful for learning compiler design.
2. Show the architecture from ONNX input to generated C++.
3. Run the prototype with `sample_model.mforge`.
4. Show supported operators and the simplified IR.
5. Explain the Phase 2 plan for actual ONNX protobuf loading.
6. Explain scope boundaries, risks, and validation strategy.
