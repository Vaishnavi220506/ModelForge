# Review Requirements

The supplied instruction manual defines three implementation phases and three project reviews.

## Review 1 Project Proposal and Design Review

Focus: relevance, problem understanding, design, methodology, feasibility, innovation, and initial implementation.

Required material:

- Project title
- Abstract
- Problem statement
- Motivation
- Objectives
- Scope
- Background study
- Compiler Design concepts
- Proposed methodology
- System architecture
- Technology stack
- Initial prototype

Review 1 rubric: topic relevance 3, problem statement 3, objectives 2, system design 4, compiler concepts 3, innovation 2, prototype 3; total 20 marks.

## Review 2 Implementation Progress Review

Demonstrate substantial working modules, source code, test cases, intermediate results, and a module-wise explanation. Planned folder: `review_2_core_implementation/`.

## Review 3 Final Project Review

Demonstrate the complete integrated compiler, source code, test results, output evidence, final report, presentation, and user instructions. Planned folder: `review_3_final_integration/`.

## Important manual constraints

- The project is strictly individual.
- The student must understand and explain all submitted work.
- AI tools may support learning, debugging, algorithms, and documentation, but the student remains responsible for validating and explaining the result.
- Maintain modular code, meaningful names, comments for complex logic, test cases, version history where possible, backups, and a development log.
